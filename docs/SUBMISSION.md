# Submission checklist

Adapt this list to the official 2026 Project Submission Guide once its final fields and video rules are published.

## Project page

- [ ] Title: **T-MINUS: Rocket & Mission Builder**.
- [ ] Short summary explains the challenge **Space Mission Design Game** and the game's build → launch → operate → learn loop.
- [ ] Add the playable build or demo video link.
- [ ] Add the GitHub repository link.
- [ ] List every NASA dataset, model or resource used, with direct source links and credits from [CREDITS.md](../CREDITS.md).
- [ ] State which AI tools were used and how; describe human review and any optional AI proxy clearly.

## Demo and pitch (3 minutes)

- [ ] **0:00–0:20 — Title:** “In 1962, Pakistan launched its first rocket, Rehbar-I, from Sonmiani near Karachi, with NASA's help. We built a game so every student here can build one.”
- [ ] **0:20–0:40 — Problem:** Explain that missions fail at component connections, and students need connected learning across orbits, rockets and subsystems.
- [ ] **0:40–2:10 — Judge Mode/live demo:** Fix the missing RF cable with HOUSTON → launch the badly bolted rocket → show joint failure at max-Q and its debrief cause → fix and fly again → reach orbit, deploy and reveal the Landsat flood-image reward (or identify the placeholder if images are not bundled).
- [ ] **2:10–2:35 — Validity:** Show the flight model equations, NASA Saturn V stage data and measured thrust-to-weight result; distinguish sourced facts from illustrative values.
- [ ] **2:35–2:50 — Impact:** Explain offline play, English/Urdu HOUSTON support and free classroom use.
- [ ] **2:50–3:00 — Roadmap:** Mention SLS/Artemis, an engine lab and classroom mode.
- [ ] Prepare concise answers: how T-MINUS differs from Kerbal Space Program; what physics is modeled; how HOUSTON is constrained; who will use it.
- [ ] Rehearse twice with a timer; assign one person to drive and one to speak.
